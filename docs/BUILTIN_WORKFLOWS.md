# คำอธิบายเวิร์กโฟลว์ในตัว

ภายในคลังโค้ดนี้มาพร้อมกับเทมเพลตเวิร์กโฟลว์จริง 4 ชุดที่ได้รับการปรับแต่งพารามิเตอร์และการเชื่อมต่อโหนดเรียบร้อยแล้ว (อยู่ที่ `api/app/gpu/templates/builtin/`) คุณสามารถนำไปใช้งานได้ทันทีโดยไม่ต้องต่อโหนด ComfyUI เองตั้งแต่เริ่มต้น

### การตั้งค่าที่เลือกได้บนหน้าเว็บของ H3 Multi-Reference (`1.4.0`)

เวิร์กโฟลว์นี้ได้รับการปรับแต่งเป็นพิเศษสำหรับอนิเมะ/CG และวิดีโอทั่วไป โดยสามารถคลิกเลือกปรับเปลี่ยนบนหน้าเว็บได้โดยตรง:

- **โหมดการสุ่มตัวอย่าง (Sampling) 5 รูปแบบ**:
  - `แบบเร็ว 4 ก้าว (Fast 4-step)`: 4-step v0.1 Turbo LoRA ประหยัด CU มากที่สุด
  - `แบบเร็ว 8 ก้าว v1.1 (Fast 8-step v1.1)` (แนะนำเป็นค่าเริ่มต้น): เวอร์ชันใหม่ 8-step v1.1 768p Turbo LoRA โครงหน้าและสรีระนิ่งกว่าแบบ 4-step มาก
  - `4 ก้าว + รีไฟน์` / `8 ก้าว v1.1 + รีไฟน์`: หลังจากสุ่มตัวอย่างรอบแรกเสร็จ จะขยายขนาดใน 3D Latent Space `1.2x` แล้วทำ Sampling รอบสองอีก 8 ก้าว ภาพจะคมชัดขึ้นอย่างเห็นได้ชัด
  - `คุณภาพสูง 20 ก้าว`: ไม่ใช้ LoRA เร่งความเร็ว สุ่มตัวอย่างด้วยโมเดลดั้งเดิมโดยตรง 20 ก้าว
- **การสลับ VAE วิดีโอ 2 รูปแบบ**:
  - `อนิเมะ/CG Seamless VAE` (แนะนำเป็นค่าเริ่มต้น): ออกแบบมาเพื่อแก้ปัญหาของ VAE ดั้งเดิมที่มักทำให้ภาพอนิเมะหน้าแดงผิดปกติ สีสันสั่นไหว หรือมีลายตาข่าย
  - `VAE ทางการดั้งเดิม`: สามารถสลับกลับไปใช้เวอร์ชันเดิมเพื่อเปรียบเทียบได้ตลอดเวลา
- **คลัง LoRA SFW คุณภาพในตัว**: มีการกำหนดค่า LoRA ปรับแต่งการเคลื่อนไหวให้เป็นธรรมชาติ, การควบคุมมุมกล้อง, แถบเลื่อนล็อกสไตล์ 2D อนิเมะ, วอลเปเปอร์เคลื่อนไหว CG ฯลฯ (ผสมผสานได้สูงสุดครั้งละ 3 ตัว) และสามารถอัปโหลดไฟล์ LoRA `.safetensors` ของคุณเองขึ้น Google Drive ผ่านหน้าเว็บได้เช่นกัน

## 2. ทำไมหลังติดตั้งใหม่จึงอยู่ในสถานะ "ฉบับร่าง (Draft)"?

เมื่อคุณเข้าสู่ระบบครั้งแรกและเปิดหน้าแท็บ "เวิร์กโฟลว์" เทมเพลตทั้ง 4 ชุดนี้จะถูกลงทะเบียนโดยอัตโนมัติ แต่ทั้งหมดจะอยู่ในสถานะ **ฉบับร่าง (Draft)** และโมเดลจริงที่เกี่ยวข้องจะอยู่ในสถานะ **ยังไม่เปิดใช้งาน (Disabled)**

การออกแบบนี้ทำขึ้นเพื่อความปลอดภัย:
- ป้องกันผู้ใช้ที่เพิ่งติดตั้งเสร็จและยังไม่ได้ตรวจสอบความต้องการการ์ดจอหรืองบประมาณ เผลอกดปุ่มสร้างแล้วระบบไปดาวน์โหลดน้ำหนักโมเดลขนาดหลายสิบ GB จนเสีย Colab CU โดยไม่ตั้งใจ
- การรีสตาร์ทเซอร์วิสจะไม่เขียนทับพารามิเตอร์ที่คุณแก้ไขในภายหลัง หรือเวิร์กโฟลว์เวอร์ชันที่เผยแพร่ไปแล้ว

## 3. จะเปลี่ยนสถานะฉบับร่างในตัวให้พร้อมใช้งานได้อย่างไร?

หลังจากที่คุณตั้งค่า Google OAuth เรียบร้อยแล้ว (ดูใน `OAUTH_SETUP.md`) พร้อมทั้งกำหนด `GPU_REAL_ENABLED=1` และอัตรางบประมาณใน `.env`:

1. ในหน้า "เวิร์กโฟลว์" ให้ค้นหาฉบับร่างที่คุณต้องการใช้ แล้วคลิก **ตรวจสอบ** (สถานะจะเปลี่ยนเป็น `validated`)
2. ดำเนินการตาม API ผู้ดูแลระบบที่ระบุไว้ใน `WORKFLOW_REVIEW.md`:
   - อนุมัติตรวจสอบโมเดลที่เกี่ยวข้อง (ยืนยันแหล่งที่มาและสัญญาอนุญาตของโมเดล)
   - อนุมัติตรวจสอบเวิร์กโฟลว์ดังกล่าว (ระบบจะล็อก commit ของ ComfyUI, ไวต์ลิสต์ของโหนด และ SHA-256 ของน้ำหนักโมเดลโดยอัตโนมัติ)
   - รันการทดสอบความพร้อมบน GPU จริงแบบจำกัดเวลาไม่เกิน 5 นาที (`real-smoke`)
   - เมื่อการทดสอบสำเร็จและ runtime ถูกทำลายโดยอัตโนมัติแล้ว ให้เรียก `accept-smoke` เพื่อตรวจรับ และคลิก **ยืนยันการเผยแพร่**

เมื่อเผยแพร่สำเร็จ คุณจะสามารถเลือกเวิร์กโฟลว์นี้ได้จากเมนูดรอปดาวน์ในหน้า "สร้างสรรค์" และส่งงานสร้างจากมือถือได้ตลอดเวลา
