# รายงานการจัดระเบียบและการตรวจสอบโค้ดโอเพนซอร์สครั้งแรก (เกณฑ์พื้นฐานในอดีต)

> เอกสารนี้บันทึกสถานะการตรวจสอบของแพ็กเกจซอร์สโค้ดครั้งแรก ไม่ได้สะท้อนถึงสถานะปัจจุบันของเวอร์ชันถัดไป โดยเวอร์ชันปัจจุบัน 0.1.28 ได้เพิ่มเทมเพลตฉบับร่างในตัว 4 ชุดแล้ว ดูรายละเอียดใน `BUILTIN_WORKFLOWS.md`; ข้อความ "ยังไม่ได้เผยแพร่ / ยังไม่ได้ส่งออก" ด้านล่างหมายถึงสถานะ ณ เวลาที่จัดระเบียบครั้งแรก

## ขอบเขตและสถานะ

นี่คือแพ็กเกจการจัดระเบียบซอร์สโค้ดแบบสแตนด์อโลน **ไม่ใช่แพ็กเกจการย้ายข้อมูลทั้งหมดจากสภาพแวดล้อมจริง (Production) และยังไม่ได้เผยแพร่บน GitHub** โดยทำการลบการเชื่อมต่อกับแพลตฟอร์มสร้างสรรค์ภายนอก ล้างข้อมูลที่เป็นความลับ และจัดระเบียบเอกสารสาธารณะตามข้อกำหนดเท่านั้น โดยไม่มีการปรับโครงสร้างฟังก์ชันการทำงานส่วนอื่น

Commit เกณฑ์พื้นฐาน: `a2a8869756f638cccbfa73ad06fcf58a73db0245` ความแตกต่างระหว่างเวอร์ชันของเวิร์กโฟลว์, คำอธิบาย commit และสตริงเวอร์ชันภายในโปรแกรมดูได้จาก README ที่รากของโปรเจกต์ โดยไม่ได้นำเวอร์ชันของเวิร์กโฟลว์ `1.4.0` มาเขียนทับเป็นเวอร์ชันของแอปพลิเคชันทั้งหมด

## สิ่งที่เก็บไว้และสิ่งที่นำออก

คงไว้ซึ่ง FastAPI/React, Google OAuth, ตัวปรับแต่ง Colab/Drive, การเตรียมแคชบน CPU, GPU worker/watchdog, LoRA, ตัวจัดคิว (Scheduler), การตรวจสอบ manifest/เวิร์กโฟลว์, การจัดการไฟล์และงาน, Migration, ไฟล์ล็อกการพึ่งพา (Dependency locks) และสัญญาอนุญาต MIT ดั้งเดิม

นำออกซึ่ง Routing และ Connector การเชื่อมต่อภายนอก, การส่งข้อมูลกลับอัตโนมัติ, ฟิลด์การแมปโปรเจกต์, ฟอร์มการตั้งค่าเว็บภายนอก, ปุ่ม/ป๊อปอัปส่งออก, API สำหรับหน้าบ้านเฉพาะทาง, การตั้งค่าเริ่มต้นที่เกี่ยวข้อง และแบบทดสอบเฉพาะทาง ความสามารถในการเปลี่ยนชื่อโปรเจกต์ในเครื่องภายในโมดูลเชื่อมต่อเดิมถูกย้ายกลับมาเป็น API อิสระ

คงไว้ซึ่งชื่อ metadata เชิงประวัติในระดับล่างของ GPU/Drive และฟิลด์สาธิตเพื่อไม่ให้กระทบต่อโปรโตคอลที่มีอยู่ ฟิลด์เหล่านี้จะไม่มีการเชื่อมต่อกับแพลตฟอร์มสร้างสรรค์ภายนอก

ความแตกต่างของโค้ดจำกัดอยู่เฉพาะที่:

- `api/app/main.py`
- `api/app/worker.py`
- `scripts/init_env.py`
- `web/src/App.tsx`
- `web/src/lib/gpu-api.ts`

ลบ: `api/app/atelier_routes.py`, `api/app/integrations/atelier.py`, `tests/test_atelier_connector.py`
เพิ่ม: `tests/test_standalone_release.py` เพื่อตรวจสอบว่า Routing/ช่องทางเข้า/การตั้งค่าการเชื่อมต่อภายนอกได้หายไปแล้ว และ Routing หลักของโปรเจกต์/งานยังคงอยู่ครบถ้วน

ไฟล์โค้ดเดิมที่คงไว้อีก 57 ไฟล์ตรงกันทุกตัวอักษร; ไฟล์เดิมทั้งหมดภายใต้ `api/app/gpu` ตรงกันทุกตัวอักษร การเปลี่ยนแปลงของการตั้งค่าและคำอธิบายมีไว้เพื่อการลดทอนข้อมูลความลับ (Sanitization), การนำการเชื่อมต่อภายนอกออก และการอธิบายแพ็กเกจโอเพนซอร์สให้ถูกต้องแม่นยำเท่านั้น

## การจัดการความเป็นส่วนตัว

ใช้วิธีส่งออกตามไวต์ลิสต์ของไฟล์ แทนที่จะคัดลอกทั้งไดเรกทอรีการดำเนินงาน โดยไม่รวมถึง:

- `.git` ดั้งเดิมและประวัติ commit
- `.env`, `.env` ในอดีต, ไฟล์ Client JSON ของ OAuth และโทเค็น
- ฐานข้อมูล, โปรเจกต์/งาน/ไฟล์ในสภาพแวดล้อมจริง, แคชบน Drive และไฟล์ผลงาน GPU
- คีย์ส่วนตัว, ข้อมูลการเข้าสู่ระบบ, Snapshot ในระบบจริง, เอกสารส่งมอบงานเก่า และสคริปต์ QA API ส่วนตัว
- Virtual Environment, node_modules, ไฟล์ที่คอมไพล์แล้ว และข้อมูลที่สร้างจากการทดสอบ

ตัวอย่าง OAuth สาธารณะเปลี่ยนมาใช้โดเมนตัวอย่างที่สงวนไว้ ส่วนการระบุชื่อผู้สร้างดั้งเดิมในสัญญาอนุญาต MIT ยังคงเก็บรักษาไว้

## สิ่งที่ยังไม่ได้ตรวจสอบและข้อจำกัด

- ไม่ได้สร้าง Colab runtime จริงใดๆ (ทั้ง CPU และ GPU), ไม่ได้รันการสร้างที่มีค่าใช้จ่ายจริง, ไม่ได้ทำการยืนยันสิทธิ์ Google หรือดาวน์โหลดโมเดล
- การทดสอบพิสูจน์ว่าคิวออฟไลน์/Mock และการประกอบแอปหลังลบการเชื่อมต่อภายนอกสามารถทำงานได้ ไม่ได้พิสูจน์ถึงคุณภาพของภาพ/วิดีโอในระบบจริง หรือการใช้ CU จริง
- Graph/manifest/object_info ที่เผยแพร่แล้วในฐานข้อมูล Production ไม่ได้ถูกส่งออกมาด้วย การติดตั้งใหม่จะมีเฉพาะเวิร์กโฟลว์สาธิตในตัวเท่านั้น
- Docker daemon ในเครื่องไม่พร้อมใช้งาน จึง**ไม่ได้อ้างว่าการบิลด์อิมเมจ Docker หรือการรันคอนเทนเนอร์ Compose ผ่านการตรวจรับแล้ว**
- คงไว้ซึ่งสไตล์เดิม; การปรับสเกล vw บนเดสก์ท็อปค่อนข้างใหญ่ โดยไม่ได้ปรับเปลี่ยน UI สำหรับจุดนี้
- ครั้งนี้ไม่ใช่การตรวจสอบช่องโหว่ความปลอดภัยแบบครบวงจร การที่ Secret Scanner ตรวจไม่พบ ไม่ได้แปลว่าความเสี่ยงด้านความปลอดภัยเป็นศูนย์
