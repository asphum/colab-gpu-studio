# Colab GPU Studio

สตูดิโอ AI ส่วนตัวสำหรับรัน ComfyUI บน Google Colab GPU สั่งงานง่ายผ่านมือถือ (สร้างภาพ + วิดีโอ H3)

ส่วนหน้าบ้าน (Frontend) เป็น Single Page Application ด้วย React ที่ออกแบบมาให้เหมาะกับการสัมผัสบนมือถือ ส่วนหลังบ้าน (Backend) ใช้ FastAPI โดยทั่วไปหน้าเว็บ คิวงาน และประวัติผลงานจะถูกบันทึกอยู่บนเซิร์ฟเวอร์ส่วนตัวของคุณ (VPS) โดยไม่กินทรัพยากร GPU แต่อย่างใด จนกว่าคุณจะกดปุ่ม "สร้าง" ระบบจึงจะส่งคำขอไปยัง Google Colab เพื่อขอใช้งาน GPU เมื่อรันเสร็จและดึงไฟล์ผลงานกลับมาแล้ว **ระบบจะทำลาย runtime ทันที ไม่ปล่อยให้ Compute Unit (CU) หมุนฟรีหรือเสียค่าใช้จ่ายโดยไม่จำเป็น**

## ทำไมถึงสร้างโปรเจกต์นี้?

1. **ประหยัด CU คือหัวใจสำคัญ**: สภาพแวดล้อม ComfyUI และน้ำหนักโมเดลขนาดใหญ่หลายสิบ GB ทั้งหมดจะถูกแคชไว้ใน Google Drive ของคุณเอง งานหนักอย่างการดาวน์โหลดโมเดลและติดตั้ง environment ปล่อยให้ CPU runtime ราคาประหยัดจัดการ ส่วน GPU ราคาแพง (T4 / L4) จะเปิดขึ้นมาเพื่อทำ 3 อย่างเท่านั้น: **ดึงแคช environment คืน → สุ่มตัวอย่างสร้างผลงาน (Sampling) → ปิดและลบอินสแตนซ์ทันที**
2. **สร้างภาพ/รันวิดีโอบนมือถือได้อย่างสะดวกสบาย**: ไม่ต้องทนลากสายเชื่อมโยงโหนด ComfyUI ที่หนาแน่นบนเบราว์เซอร์มือถือ และไม่ต้องคอยจ้องแท็บ Colab เพื่อป้องกันการหลุดการเชื่อมต่อ หน้าบ้านจะเรนเดอร์ฟอร์มกรอกพารามิเตอร์ตามเวิร์กโฟลว์ให้อัตโนมัติ ปิดหน้าจอมือถือไประบบเบื้องหลังก็ยังคงทำงานตามคิวต่อไปได้
3. **มาพร้อมเทมเพลตเวิร์กโฟลว์ที่ปรับแต่งมาแล้ว 4 ชุด**: ติดตั้งพร้อมใช้ด้วย Krea+MOSS Dual Sampling, MOSS Text-to-Image, MiniMax H3 ภาพแรก (และภาพท้าย) เป็นวิดีโอพร้อมเสียง, MiniMax H3 วิดีโอพร้อมเสียงจากภาพอ้างอิงหลายภาพ (รองรับภาพอ้างอิงสูงสุด 6 ภาพ, ตัวเร่งความเร็ว 8-step Turbo v1.1, การรีไฟน์ Latent 1.2x, อนิเมะ Seamless VAE และ LoRA ควบคุมท่าทาง/มุมกล้อง/สไตล์ SFW หลากหลายรูปแบบ)

> **ข้อควรระวังด้านความปลอดภัย**: เมื่อติดตั้งใหม่ ระบบจะเปิดเฉพาะโหมดสาธิตออฟไลน์ `demo-mock` เป็นค่าเริ่มต้น (ไม่เชื่อมต่อ Google, ไม่หักคะแนน CU) ส่วนเวิร์กโฟลว์จริงทั้ง 4 ชุดจะอยู่ในสถานะ "ฉบับร่าง" (Draft) ในรายการเวิร์กโฟลว์ คุณจำเป็นต้องผูก Google OAuth ของตนเอง ยืนยันสัญญาอนุญาตของโมเดล และทดสอบให้ผ่านก่อน จึงจะสามารถเปิดใช้งานจริงได้ เพื่อป้องกันการกดพลาดแล้วเสีย CU โดยไม่ตั้งใจ

## เริ่มต้นใช้งานอย่างรวดเร็ว

### วิธีที่ 1: รันด้วย Docker คำสั่งเดียว (แนะนำสำหรับการติดตั้งบน VPS)

จำเป็นต้องติดตั้ง Docker, Docker Compose และ Python ก่อน (เพื่อใช้สร้างคีย์สุ่มเริ่มต้น):

```bash
# 1. สร้างไฟล์คอนฟิกส่วนตัว .env (เปลี่ยนโดเมนเป็นของคุณเอง หากทดสอบในเครื่องไม่ต้องแก้ไข)
uv run python scripts/init_env.py --site-url https://โดเมนของคุณ

# 2. เริ่มต้นเซอร์วิส (ประกอบด้วยคอนเทนเนอร์ api / worker / watchdog รวม 3 ตัว)
docker compose up -d --build
```

บริการจะดักฟังเฉพาะภายในเครื่องที่ `127.0.0.1:8788` เป็นค่าเริ่มต้น สำหรับการเข้าถึงผ่านเครือข่ายสาธารณะ แนะนำให้ใช้ Caddy หรือ Nginx ทำ Reverse Proxy และเปิดใช้งาน HTTPS ข้อมูลทั้งหมดจะถูกเก็บไว้ใน Volume `studio-data` **ห้ามพิมพ์คำสั่ง `docker compose down -v` เด็ดขาด เพราะจะทำให้ Volume ข้อมูลถูกลบ**

### วิธีที่ 2: รันบนเครื่องโดยตรง (Local Development)

จำเป็นต้องมี Python 3.11+, `uv`, Node.js และ `npm`:

```bash
uv sync --extra test
uv run python scripts/init_env.py --site-url http://127.0.0.1:8788
npm --prefix web ci
npm --prefix web run build

# เทอร์มินัล 1: รัน Web API
uv run --env-file .env uvicorn app.main:app --app-dir api --host 127.0.0.1 --port 8788 --no-access-log

# เทอร์มินัล 2: รัน Worker จัดการคิวงาน
uv run --env-file .env python -m app.worker worker

# เทอร์มินัล 3: รัน Watchdog ตรวจจับงานหมดเวลาและล้างข้อมูล
uv run --env-file .env python -m app.worker watchdog
```

เมื่อเริ่มต้นแล้ว ให้เปิดเบราว์เซอร์ไปที่ `http://127.0.0.1:8788` รหัสผ่านสำหรับเข้าสู่ระบบจะอยู่ในฟิลด์ `STUDIO_PASSWORD` ในไฟล์ `.env` ที่เพิ่งสร้างขึ้น

## วิธีเชื่อมต่อ Google Colab ของตนเองเพื่อรันโมเดลจริง

เพื่อป้องกันการรั่วไหลของคีย์และการหักค่าใช้จ่ายโดยไม่ตั้งใจ โปรเจกต์นี้จะปิดการใช้งาน GPU จริงไว้เป็นค่าเริ่มต้น (`GPU_REAL_ENABLED=0`) การเชื่อมต่อกับบัญชีของคุณมีขั้นตอนตามลำดับดังนี้:

1. **ผูก Google OAuth**: ทำตามขั้นตอนใน [การตั้งค่า Google OAuth และ Drive](docs/OAUTH_SETUP.md) นำเข้าไฟล์ Web Client JSON ของ Google Cloud ในหน้าการตั้งค่าเว็บ จากนั้นคลิกเชื่อมต่อ Colab และ Drive ตามลำดับ
2. **เปิดใช้งานเวิร์กโฟลว์ในตัวหรือนำเข้าเวิร์กโฟลว์ใหม่**: อ้างอิงจาก [คำอธิบายเวิร์กโฟลว์ในตัว](docs/BUILTIN_WORKFLOWS.md) และ [ขั้นตอนการตรวจสอบโมเดลและเวิร์กโฟลว์](docs/WORKFLOW_REVIEW.md) กำหนดค่า `GPU_REAL_ENABLED=1` ตั้งค่าขีดจำกัดงบประมาณ ตรวจสอบ และเปิดใช้งานเวิร์กโฟลว์

## ข้อควรระวังและข้อจำกัดความรับผิดชอบ

- **ดูแลรักษาคีย์ของคุณให้ปลอดภัย**: ห้ามอัปโหลด `.env`, ฐานข้อมูล หรือไฟล์ JSON ของ Google OAuth Client ขึ้นคลังโค้ดสาธารณะหรือส่งให้ผู้อื่นเด็ดขาด ค่า `ENCRYPTION_KEY` ใน `.env` มีไว้สำหรับถอดรหัส OAuth token ในฐานข้อมูล ขอแนะนำให้สำรองข้อมูลไว้แบบออฟไลน์ หากทำหายจะต้องทำการยืนยันสิทธิ์ใหม่ทั้งหมด
- **การคิดค่าใช้จ่ายยึดตาม Google เป็นหลัก**: ค่า CU ที่แสดงบนหน้าเว็บเป็นเพียงค่าประมาณการจากการคำนวณประวัติงานเก่า จำนวน Compute Unit ที่ถูกหักจริงโปรดยึดตามคอนโซลหลังบ้านของ Google Colab เป็นหลัก
- **ออกแบบสำหรับการใช้งานส่วนบุคคล**: โปรเจกต์นี้ออกแบบมาสำหรับการใช้งานส่วนตัวเป็นหลัก ไม่ได้ทำระบบแยกผู้เช่า (Multi-tenancy) จึงไม่ควรนำไปเปิดให้บริการ SaaS สาธารณะที่มีผู้ใช้หลายคนโดยตรง
